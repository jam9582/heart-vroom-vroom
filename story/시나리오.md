# 「심장이 부릉부릉」 시나리오

## 플레이 시간
- 공통 파트 약 3분 + 루트 파트 약 5분 = **한 번 플레이 약 8분**
- 대사 1줄을 약 4초로 계산 (공통 약 45줄, 루트마다 약 75줄)

## 태그 규칙
| 태그 | 뜻 |
|---|---|
| `[배경: 파일명]` | backgrounds 폴더의 그림 |
| `[필터: 밤 / 세피아 / 저녁 / 비 / 정전 / 벼락 / 해제]` | 같은 배경에 색 필터 |
| `[등장: 캐릭터]` `[퇴장: 캐릭터]` | 스탠딩 표시·숨김 |
| `[램프: 캐릭터 색]` | 파랑 평온, 분홍 설렘, 빨강 화남·N 모드, 노랑 당황, 회색 희미해짐 |
| `[효과음: 이름]` | |
| `[카드: 연도 · 내용]` | 연대기 카드 팝업 |
| `[호감: 캐릭터 +1]` | 호감도 |
| `[이동: 라벨]` | 해당 장면으로 이동 |

- 이름 없는 줄은 내레이션, 괄호 대사는 포니의 속마음입니다.

## 분기 규칙
1. 공통 선택지 1·2에서 고른 캐릭터의 호감이 오릅니다.
2. 공통 선택지 3에서 **루트가 정해집니다**. 아반떼 루트는 선택지 1·2에서 **둘 다 아반떼를 골랐을 때만** 보입니다.
3. 루트마다 선택지가 3개 있습니다. 좋은 답을 **2개 이상** 고르면 해피 엔딩, 아니면 노멀 엔딩입니다.
4. 마지막 선택에서 "남는다"를 고르면 공통 배드 엔딩입니다.
